# Jogos Digitais — Projeto Unity

Repositório acadêmico para experimentos com Unity. No estado atualmente versionado, contém a estrutura inicial de um projeto **Unity 6**, incluindo a cena de exemplo e as configurações de renderização; não há, neste repositório, uma implementação documentada de jogo finalizado.

## Ambiente registrado

- **Editor:** Unity `6000.3.22f1`, conforme `ProjectSettings/ProjectVersion.txt`.
- **Renderização:** Universal Render Pipeline (URP).
- **Entrada:** Unity Input System.

## Como abrir

1. Clone o repositório.
2. Instale a versão do Unity indicada acima, quando disponível.
3. Abra a pasta raiz no Unity Hub.
4. Aguarde a importação dos pacotes definidos em `Packages/manifest.json`.

## Estrutura

- `Assets/`: cena de exemplo, recursos e arquivos de configuração.
- `Packages/`: dependências do Unity.
- `ProjectSettings/`: configurações do projeto.

> Este repositório é separado de [Aberratio Mentis](https://github.com/GMRsVoiage/Aberratio-Mentis), que possui documentação e desenvolvimento próprios.
